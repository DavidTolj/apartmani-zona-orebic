APARTMANI ZONA - ISPRAVNA GITHUB STRUKTURA

VAZNO: U GitHub Desktop repozitorij kopiraj SAV SADRZAJ ove mape, ali nemoj premjestati slike iz mape images.

Nakon kopiranja korijen repozitorija mora izgledati ovako:

index.html
index-en.html
index-de.html
index-cs.html
index-pl.html
netlify.toml
.gitattributes
images/
  orebic-final/
  units-final/

Ako u korijenu vidis desetke .jpg slika, struktura NIJE dobra.

Postupak:
1. U GitHub Desktopu otvori Repository > Show in Explorer.
2. U toj mapi obrisi sve vidljive stare datoteke i mape. Ne diraj skrivenu .git mapu.
3. Iz OVE mape kopiraj sve zajedno u praznu mapu repozitorija.
4. Vrati se u GitHub Desktop.
5. Summary: Ispravna zavrsna verzija stranice
6. Commit to main.
7. Push origin.
8. Pricekaj Netlify deploy 1-3 minute.
